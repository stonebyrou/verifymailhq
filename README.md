# VerifyMailHQ

Pre-send hygiene for a list you already have. Clean the file, then check a mailbox if you need to. This is not a sending platform.

**Use it:** [verifymailhq.com](https://verifymailhq.com) · [Email List Cleaner](https://verifymailhq.com/email-list-cleaner/) · [Free Email Verifier](https://verifymailhq.com/email-verifier/)

## What it does

Two jobs, two pages:

- **[Email List Cleaner](https://verifymailhq.com/email-list-cleaner/)** — upload a CSV or TXT (or paste a column). Local sort flags syntax, duplicates, role inboxes, disposable domains, and missing MX. You download classified files. No signup to download.
- **[Free Email Verifier](https://verifymailhq.com/email-verifier/)** — type one address. Syntax and MX first. Existence is a separate check and spends a credit.

Cleaning is not proof a mailbox exists. Catch-all (accept-all) domains stay risky. We do not promise 100% accuracy.
